GOOGLE DORKING

A practical collection of Google advanced-search operators for passive reconnaissance and security assessments. Replace target.com with a domain you own or are explicitly authorized to assess. Select a query to run it on Google.

[ 01 ]GOOGLE DORK

Scope Filter

site:target.com ↗

Limits search results to the specified target domain.

[ 02 ]GOOGLE DORK

Subdomain Finder

site:target.com -www ↗

Excludes results containing www; useful as a rough search refinement, but not a reliable subdomain enumeration method.

[ 03 ]GOOGLE DORK

Public Documents

site:target.com ext:pdf ↗

Finds PDF documents indexed for the target domain. Review only material you are authorized to access.

[ 04 ]GOOGLE DORK

Configuration Files

site:target.com (ext:xml OR ext:conf OR ext:cnf) ↗

Searches for indexed XML and configuration-file extensions. Do not access or use exposed secrets.

[ 05 ]GOOGLE DORK

Admin Portals

site:target.com (inurl:admin OR inurl:login) ↗

Finds indexed administration and login pages; do not attempt access without explicit authorization.

[ 06 ]GOOGLE DORK

Open Directories

intitle:"index of" "parent directory" ↗

Finds pages that appear to expose directory listings.

[ 07 ]GOOGLE DORK

SQL Error Messages

site:target.com intext:"sql syntax near" ↗

Searches for pages containing a common SQL error string; a result alone does not prove SQL injection.

[ 08 ]GOOGLE DORK

Pastebin References

site:pastebin.com "target.com" ↗

Finds public Pastebin pages mentioning the target domain. Do not retrieve, share, or test credentials.

[ 09 ]GOOGLE DORK

GitHub References

site:github.com "target.com" ↗

Finds public GitHub pages referencing the target domain; verify findings responsibly and report exposed secrets.

[ 10 ]GOOGLE DORK

Log Files

filetype:log intext:password ↗

Searches indexed log files for password-related text. Avoid opening, copying, or using credentials.

[ 11 ]GOOGLE DORK

Environment Files

intext:"index of /" ".env" ↗

Looks for directory listings that mention .env files. Treat any discovered secrets as sensitive.

[ 12 ]GOOGLE DORK

Backup Files

site:target.com (ext:bkf OR ext:bkp OR ext:bak) ↗

Searches for common backup-file extensions indexed under the target domain.

AUTHORIZED USE ONLY // These queries may surface sensitive documents, credentials, configuration files, logs, or administrative interfaces. Use them only within an approved scope. Do not access, download, disclose, or use exposed secrets or attempt to log in to discovered systems. Report accidental exposure through the owner's responsible-disclosure channel.

BLACKBIRD

Blackbird is an OSINT username and email discovery tool. It checks whether a supplied identifier appears across hundreds of online platforms, bringing distributed account-presence checks into one workflow. Use results as investigative leads, not proof that accounts belong to the same person.

[ 01 ]IDENTITY DISCOVERY

USERNAME & EMAIL SEARCH

Search a username or email address across a large set of websites and social platforms. Username lookups integrate the community-maintained WhatsMyName dataset, which provides the underlying site checks.

USERNAME ENUMERATION · EMAIL PRESENCE
[ 02 ]RESULT ANALYSIS

FILTERS & REPORTING

Review detected profiles, apply filters, and export findings in formats such as PDF or CSV. Treat matches as candidate accounts: usernames can be shared, platform responses change, and automated checks can produce false positives or miss accounts.

RESULT TRIAGE · PDF / CSV EXPORT
[ 03 ]AI-ASSISTED CONTEXT

OPTIONAL AI PROFILE

The project documentation describes an optional AI summary based on the names of services where matches were reported. This is contextual inference, not identity verification or evidence of a person's interests, behavior, or real-world identity.

AI SUMMARY · VERIFY EVERY LEAD
WORKFLOW // Start with an identifier you are authorized to investigate. Review each returned platform URL manually, compare independent signals before correlating accounts, record the date and method, and preserve only information necessary for the defined purpose. A negative email search is not evidence that an address has no online accounts; coverage is limited to the services checked.
OPEN BLACKBIRD ↗ SOURCE & DOCUMENTATION ↗

PRIVACY & AUTHORIZED USE // Use this tool only where you have a lawful basis and a legitimate, proportionate purpose. Account discovery can expose personal information. Do not use it for stalking, harassment, doxxing, credential attacks, or decisions based on unverified matches. Check the current project documentation, platform terms, applicable data-protection rules, and the tool's data handling before use.

OSIRIS

OSIRIS (Open Source Intelligence) is a browser-based global intelligence dashboard that brings multiple public-data feeds together on an interactive world map. It is designed for situational awareness and exploratory OSINT, rather than as a standalone verification or investigative system.

[ 01 ]GLOBAL MONITORING

LIVE GEOINT & SITUATIONAL AWARENESS

Visualize public CCTV feeds, aircraft and maritime activity, satellite positions, earthquakes, weather events, conflict and high-risk areas, critical infrastructure datasets, news streams, and mapped cyber or malware threat indicators. Available layers and geographic coverage depend on the data provider.

GLOBAL MAP · MULTI-SOURCE OSINT
[ 02 ]ENTITY INVESTIGATION

TRACK & ENRICH

Select mapped entities such as aircraft or vessels to inspect the associated public information and contextual details. The dashboard can help correlate locations, movements, events, and related open-source data during an initial research workflow.

AVIATION · MARITIME · SATELLITES
[ 03 ]INTELLIGENCE LAYERS

CONTEXT & EARLY WARNING

Toggle map layers to build a regional picture of incidents, conflict zones, infrastructure, environmental events, and public information feeds. Some builds also expose market-analysis or AI-assisted overview features; treat these as experimental context, never as financial or operational advice.

MAP LAYERS · ALERTS · NEWS
HOW TO USE IT // Open the live map below, enable only the layers relevant to your research, zoom into the area of interest, and select individual markers to inspect their available context. Cross-check important findings with the original provider and independent sources. Data may be delayed, incomplete, geographically biased, or unavailable.
