IPv4 SUBNETTING

Break an IPv4 network into smaller logical networks. Read CIDR notation, calculate subnet boundaries, identify usable hosts, and decide whether traffic stays local or crosses a gateway.

01 // THE CORE IDEA

A subnet mask separates the network portion of an address from the host portion. A prefix such as /26 means 26 network bits and 6 host bits in a 32-bit IPv4 address.

/24 11111111.11111111.11111111.00000000
/26 11111111.11111111.11111111.11000000

/26 = 255.255.255.192 · 2 bits borrowed from the original /24 · 4 equal subnets · 64 total addresses per subnet · 62 usable host addresses.

*For conventional IPv4 subnets, subtract the network and broadcast addresses. /31 point-to-point links and /32 host routes are special cases.

02 // SPLIT 192.168.10.0/24 INTO FOUR /26 SUBNETS

The block size is 256 − 192 = 64. Therefore, the network boundaries increase by 64 in the final octet.

04 // FIND THE SUBNET FOR 192.168.10.77/26

  1. Mask: 255.255.255.192.
  2. Block size: 256 − 192 = 64.
  3. Subnet ranges start at 0, 64, 128, and 192. The value 77 falls in the 64–127 block.
  4. Network: 192.168.10.64/26.
  5. Usable range: 192.168.10.65 – 192.168.10.126.
  6. Broadcast: 192.168.10.127.
Fast check: 77 AND 192 = 64 in the final octet, so the network address ends in .64.

05 // LOCAL DELIVERY OR DEFAULT GATEWAY?

A host compares the destination against its own subnet. If the destination is on the same subnet, it resolves the peer's Layer 2 address and sends directly. If the destination is outside the subnet, it sends the packet to its configured default gateway.

Example: 192.168.10.77/26 can reach 192.168.10.100/26 directly. For 192.168.10.140/26, it forwards the packet to its gateway.

Subnetting defines Layer 3 IP ranges. VLANs separate Layer 2 broadcast domains; routing, ACLs, and firewall rules determine what can communicate between networks.

06 // OPERATOR CHECKLIST

  • Count network bits from the CIDR prefix; the remaining bits are host bits.
  • Calculate the block size in the octet where the mask is neither 255 nor 0.
  • Network address = first address in the block; broadcast = last address.
  • Usable host range sits between network and broadcast for conventional subnets.
  • Validate your result with ipcalc or sipcalc during practice.
