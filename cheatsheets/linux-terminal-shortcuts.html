LINUX, I3 & KITTY SHORTCUTS

Quick reference for Bash, i3 window management, Kitty internal splits, and the commands used to validate and reload your 0x0ps Kali workstation. Search the reference below or use your browser’s print function to save it as a PDF.

01 // CURSOR CONTROL

Ctrl+A
Move cursor to the beginning of the line
Ctrl+E
Move cursor to the end of the line
Alt+F
Move cursor forward by one word
Alt+B
Move cursor backward by one word

02 // TEXT CONTROL

Ctrl+U
Clear the line before the cursor
Ctrl+K
Clear the line after the cursor
Ctrl+W
Remove the word to the left of the cursor
Alt+D
Remove the word to the right of the cursor
Ctrl+Y
Paste the most recently cut text (yank)
Tab
Auto-complete a command, file, directory, or path

03 // JOB CONTROL

Ctrl+C
Interrupt the foreground process (SIGINT)
Ctrl+Z
Suspend the foreground job (SIGTSTP); it can often be resumed with fg
Ctrl+S
Pause terminal output on terminals using software flow control
Ctrl+Q
Resume output paused by Ctrl+S (when software flow control is enabled)

04 // SESSION CONTROL

Ctrl+L
Clear the visible terminal screen
Ctrl+D
Delete the character under the cursor; on an empty prompt, send EOF and usually exit the shell
Ctrl+Alt+T
Open a terminal window on many desktop environments (desktop-dependent)

05 // HISTORY SEARCH

Ctrl+R
Reverse-search command history
Ctrl+P
Recall the previous command from history
Ctrl+N
Move to the next command in history
Alt+.
Insert the last argument of the previous command
!!
Re-run the previous command (review it first if it uses elevated privileges or changes system state)
!<cmd>
Run the most recent history command beginning with the specified prefix

06 // 0x0PS KALI WORKSTATION — I3 & KITTY

Alt+Shift+H
Create a side-by-side internal split in Kitty (hsplit)
Alt+Shift+V
Create a top/bottom internal split in Kitty (vsplit)
Alt+Shift+W
Close the active Kitty split/window
Ctrl+Arrow keys
Move focus to the neighboring Kitty split
Ctrl+Shift+F5
Reload the Kitty configuration
Mod+Enter
Open a new Kitty terminal from i3 (Mod is configurable; this profile may use Alt/Option)
Mod+Shift+Enter
Launch the configured Kitty three-pane layout script
i3 -C -c ~/.config/i3/config
Validate the i3 configuration without applying it
i3-msg reload
Reload the i3 configuration
grep -nE 'copyq show|split v' ~/.config/i3/config
Check the CopyQ and i3 split bindings in the active i3 configuration
sed -i 's/^[[:space:]]*bindsym \$mod+Shift+v exec copyq show/# bindsym \$mod+Shift+v exec copyq show/' ~/.config/i3/config && i3-msg reload
Disable the conflicting CopyQ binding and reload i3. Run only if that exact binding exists in your config.
Key distinction: Kitty splits are internal terminal panes. They are not the same as i3 container splits (Mod+h and Mod+v). The repository disables the CopyQ Mod+Shift+v binding so it cannot intercept Kitty's Alt+Shift+V shortcut. The Mod key is set by set $mod in ~/.config/i3/config; on the user's Mac keyboard profile it is mapped to Alt/Option.
Shell note: These shortcuts mainly describe Bash/Readline behaviour. Some depend on the shell, terminal emulator, desktop environment, or terminal flow-control settings. Ctrl+S can appear to freeze a terminal when software flow control is enabled; Ctrl+Q resumes it. Be cautious with !! and history expansion before running commands with elevated privileges.
